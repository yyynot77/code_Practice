**适用题型：**
数组
原地修改
保留一部分元素/删除一部分元素
不要求或保留顺序

**关键词**：原地 删除/移动 返回新长度 不用额外数组

**核心思想**：一个指针负责遍历，另外一个指针负责“写入合格元素”

指针定义：


| i   | 扫描指针（永远向前看一个元素）      |
| --- | -------------------- |
| k   | 写指针（永远向着“下一个可以写的位置”） |
模板：
```
int k = 0;
for(int i=0;i<nums.length;i++){
	if(nums[i]满足条件){
		nums[k] = nums[i];
		k++;
	}
}
return k;
```
i从0到nums.length-1
k初始值一定是0
k++只能出现在if里
