# 快慢指针

## 适用题型

- 数组原地修改
- 保留一部分元素
- 删除一部分元素
- 移动元素
- 返回新长度

关键词：

- 原地
- 删除
- 移动
- 返回新长度
- 不使用额外数组

## 核心思想

一个指针负责扫描，另一个指针负责写入。

| 指针 | 作用 |
| --- | --- |
| `fast` / `i` | 扫描数组，判断当前元素是否应该保留 |
| `slow` / `k` | 写入位置，表示下一个合格元素应该放在哪里 |

## 基础模板

```java
int slow = 0;

for (int fast = 0; fast < nums.length; fast++) {
    if (nums[fast] 满足保留条件) {
        nums[slow] = nums[fast];
        slow++;
    }
}

return slow;
```

要点：

- `fast` 每轮都向前走。
- `slow` 只在写入有效元素后移动。
- `slow` 左边始终是处理好的有效区间。
- 数组 `slow` 后面的内容通常不用管。

## 典型题：27. 移除元素

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        int slow = 0;

        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != val) {
                nums[slow] = nums[fast];
                slow++;
            }
        }

        return slow;
    }
}
```

## 典型题：283. 移动零

先把非零元素写到前面，再把后面补成 0。

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int slow = 0;

        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != 0) {
                nums[slow] = nums[fast];
                slow++;
            }
        }

        while (slow < nums.length) {
            nums[slow] = 0;
            slow++;
        }
    }
}
```

## swap 写法和覆盖写法

覆盖写法：

- 适合“只关心前 k 个元素”的题。
- 赋值次数少。
- 逻辑更直接。

swap 写法：

- 适合需要交换两个位置元素的场景。
- 如果题目不关心被删除元素的位置，swap 反而多做了工作。

## 复盘检查

- `slow` 表示什么？
- `slow++` 为什么只能在写入后发生？
- 为什么返回 `slow`？
- 为什么空间复杂度是 `O(1)`？
- 当前题是否需要保持元素原顺序？
