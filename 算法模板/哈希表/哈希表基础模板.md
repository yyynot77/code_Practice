# 哈希表基础模板

## 1. 值到下标映射

适用：`Two Sum`、是否存在配对、一次遍历找互补值。

```java
import java.util.HashMap;

HashMap<Integer, Integer> map = new HashMap<>();

for (int i = 0; i < nums.length; i++) {
    int need = target - nums[i];

    if (map.containsKey(need)) {
        return new int[]{map.get(need), i};
    }

    map.put(nums[i], i);
}
```

要点：

- 先查再放，防止同一个元素重复使用。
- `map` 里保存的是“之前见过的信息”，不是“当前所有信息”。
- 本题中 key 是数字，value 是下标。

## 2. 常用语法

```java
map.put(key, value);
map.containsKey(key);
map.get(key);
```

注意：

- `HashMap` 的 `M` 要大写。
- `containsKey` 返回 boolean。
- `get` 返回 key 对应的 value。
