# 167. Two Sum II - Input Array Is Sorted

- 难度: Easy
- 模式: 有序数组双向指针
- 结论: 数组有序时, 一左一右夹逼比哈希表更直接, 还能把空间降到 `O(1)`

## 模板识别

- 题目给了有序数组
- 要找两个数, 且只需要一组答案
- 当前和过大或过小时, 可以利用单调性只移动一个方向

## 稳定写法

```java
int left = 0, right = numbers.length - 1;
while (left < right) {
    int sum = numbers[left] + numbers[right];
    if (sum == target) {
        return new int[] { left + 1, right + 1 };
    }
    if (sum < target) {
        left++;
    } else {
        right--;
    }
}
return new int[0];
```

## 为什么这样移动

- 如果 `sum < target`, 右指针左移只会让和更小或不变, 不能补足差值, 所以只能移动左指针
- 如果 `sum > target`, 左指针右移只会让和更大或不变, 所以只能移动右指针
- 这道题的关键不是“会双指针”, 而是能把单调性讲清楚

## 容易错的点

- 忘了题目返回的是 `1-based index`
- 明明有序还先写哈希表, 模板切换太慢
- 只会背“左小右大”, 说不清为什么某一侧不该动

## 面试复述

- 有序数组意味着指针移动具有可预测的单调效果
- 当前和偏小, 只能让左边变大
- 当前和偏大, 只能让右边变小
- 所以每一步都能排除一整类无效状态, 时间 `O(n)`, 空间 `O(1)`
