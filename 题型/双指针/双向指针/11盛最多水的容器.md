# 11. 盛最多水的容器

- 难度: Medium
- 模式: 双向指针 + 贪心移动短板
- 结论: 面积由宽度和短板共同决定, 宽度每次都会变小, 所以只有提升短板才有机会变优

## 模板识别

- 两端向中间收缩
- 每一步都计算当前答案
- 指针移动规则由“谁限制当前解”决定

## 稳定写法

```java
int left = 0, right = height.length - 1;
int best = 0;
while (left < right) {
    int area = (right - left) * Math.min(height[left], height[right]);
    best = Math.max(best, area);
    if (height[left] <= height[right]) {
        left++;
    } else {
        right--;
    }
}
return best;
```

## 为什么移动短板

- 当前面积被较短的一边限制
- 无论移动哪边, 宽度都会变小
- 如果移动长板, 短板不变, 面积上限不会超过当前状态
- 只有移动短板, 才可能遇到更高的板, 从而抵消宽度缩小的损失

## 容易错的点

- 看到面积就误以为需要枚举所有组合
- 移动长板, 本质上没有改变限制高度
- 把“可能变优”误说成“保证变优”; 实际只是保留唯一有机会变优的方向

## 面试复述

- 暴力是 `O(n^2)`, 但很多状态可以被支配关系直接排除
- 当前解由短板决定, 宽度一定缩小
- 所以保留短板提升的可能性, 丢掉长板不可能更优的分支
- 时间 `O(n)`, 空间 `O(1)`
