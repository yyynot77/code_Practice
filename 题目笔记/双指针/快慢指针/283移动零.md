官方链接：[283. 移动零 - 力扣（LeetCode）](https://leetcode.cn/problems/move-zeroes/description/)

题目：数组nums，编写函数把所有0移动到数组末尾，其他元素保持顺序
**再不复制数组情况下原地对数组操作**

模板：快慢指针

问题：
k = ？
i从那个元素开始遍历
if(nums[i]所需满足的条件)

解决思路
套用快慢指针模板

第一次提交错误问题：
```java
if(nums[i] != 0){
                nums[k] = nums[i];
                nums[i] = 0;
                k++;
```

我直接在遍历过程中直接对数组进行了置零操作
```
 nums[i] = 0;
```
导致
测试用例 nums=[1]时，算法会直接把元素化为0

第二次提交错误问题：
```java
        if(nums.length > 1){
        for(int i=0;i<nums.length;i++){
            if(nums[i] != 0){
                nums[k] = nums[i];
                nums[i] = 0;
                k++;
            }
        }
    }
```
我想单独元素可以直接用条件排除
导致
测试用例 nums=[1,0]时，问题仍然出现输出结果为[0,0]

最终我选择再用一个循环条件以k为起始，完成逻辑
```java
 for(int j = k;j < nums.length;j++){
            nums[j] = 0;
        }
```
