官方链接：[26. 删除有序数组中的重复项 - 力扣（LeetCode）](https://leetcode.cn/problems/remove-duplicates-from-sorted-array/)
题目：非严格递增排列数组nums，**原地删除**重复出现元素，使每一个元素只出现一次，返回删除后的新长度。

输入输出示例
输入：nums = [1,1,2]
输出：2, nums = [1,2,_]

模板：快慢指针

问题：
k = ？
i从那个元素开始遍历
if(nums[i]所需满足的条件)

解决思路：
1.题目中所隐含的条件是递增数列
2.第零个元素必是不重复元素，所以k和i均可以从第一个元素开始
3.nums[i]满足的条件：k-1与k，k是下一个要写入的位置，k-1是辨别指针i所指元素是否为相同元素辨别条件，因为最终结果是返回数组中k个元素，所以后续条件可以无需关心
因此：


```
int k=1;
for(int i=1;i<nums.length;i++){
	if(nums[i] != nums[k-1]){
		nums[k] = nums[i];
		k++;
	}
}
```
