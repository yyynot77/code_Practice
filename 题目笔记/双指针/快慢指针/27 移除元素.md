官方链接：[27. 移除元素 - 力扣（LeetCode）](https://leetcode.cn/problems/remove-element/)

题目：原地过滤数组中等于val的元素，返回列表不等于val值的个数

模板：快慢指针

错误问题：
1.应该关注怎么处理坏元素而不是怎么收好元素
```
if(nums[i] == val){
    nums[i] = nums[k];
}

```
后果：
- 覆盖未处理元素
- 数据被污染
- 逻辑复杂
2.快慢指针角色混乱
i既当扫描又当写入
k又读又写
两个指针相互干扰

正确分工：
i -> 只负责扫描/只读
k ->只写/记录位置
