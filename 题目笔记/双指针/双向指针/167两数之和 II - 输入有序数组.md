官方链接：[167. 两数之和 II - 输入有序数组 - 力扣（LeetCode）](https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/description/)
题目：给一个下标从1开始的数组，该数组非递减顺序排列，用双指针左右两端开始找，两个指针所对应的元素等于target就返回两个指针的值，不可以使用重复元素

错误原因：
第一次提交错误代码如下
```
while (left < right) {
    if (numbers[left] + numbers[right] != target) {
        right--;
    } else {
        resalt[0] = left;
        resalt[1] = right;
    }
}

```
我当时错误地将双指针问题，  
理解成“固定 left，只调整 right 的单向搜索”，  
从而破坏了双指针对称收敛的前提。
==重点==：等于target的时候我的指针没有更改，所以会一直陷入在while循环里面

==正确思路：==
按照对向指针模板：
双指针模板要求：  
在 `while(left < right)` 中，每一轮循环必须满足以下三者之一：

1. 命中目标 → 直接 return
    
2. 条件不足 → left++
    
3. 条件超出 → right--
首先先确定最终值（最终值是可以不断更改的）
```
if(nums[left] + nums[right] == target){
	return new int[] {left+1,right+1} //因为数组从1开始
}
```
然后写左右指针更改的条件
本题因为是按照非递排序的，所以可以将两个指针相加的值与target进行对比，如果小了就说明需要移动left，反之移动right
```
if(sum < target){
	left++;
} else{
	right--;
}
```

在整理笔记的时候有个java语法点需要注意
正确的语法应该是 new int[] {}
**数组长度和初始化列表不能同时出现**
或者 new int[2]
