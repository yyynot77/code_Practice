官方链接：[11. 盛最多水的容器 - 力扣（LeetCode）](https://leetcode.cn/problems/container-with-most-water/description/)
题目：给一个整数数组，数组中的元素相当于是盛水容器的高度，找出两个元素使其构成的容器能容纳最多的水

模板：双向指针

错误原因：
我最初的建模方式


我一开始将问题 **整体转换成“面积优化问题”**，认为需要同时处理两个条件：
- **宽度条件**：  
    left 越小、right 越大，`right - left` 越大，面积越有优势
    
- **高度条件**：  
    两个边界高度不能相差太大，否则短板会限制面积
    
基于这个想法，我尝试：
- 设定一个 **“标准面积 / 阈值面积”**
- 若当前面积小于该标准面积，则通过移动指针尝试获得更优解
- 指针移动规则采用：
    - 比较 `height[left] + height[right]`
    - 与相邻组合 `height[left+1] + height[right]`、`height[left] + height[right-1]` 的大小
    - 选择“看起来高度更优”的方向移动

实际上这个问题应该舍弃关于长度（right - left）的问题（因为长度不可控），直接转化为高度的问题（高度是决定性因素），我既想控制高度又想控制长度导致出错。

其次我想设置一个标准面积作为评判是否移动指针的标准，实际上评判标准应该与左右指针相关，本题要比较的是两个指针的高度，最小的高度决定了能装多少水

最后我设置指针变化的操作有问题，我将左右两侧指针和他们相邻的元素比较，不具有准确性保障，比如我左右两侧都是与该指针相比较小的元素，但是后续有比他更高的元素，则会导致结果完全不正确

本题正确思路应该为

首先判断是否为最优解

```

            max_area = Math.max(max_area,area);
```

然后判断指针是否要移动，因为取决于所对应元素最短的那个指针，所以比较left和right指针，使其不断迫近最优解
```
    if(height[left] < height[right]){
                left++;
            } else{
                right--;
            }
```
