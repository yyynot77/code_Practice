## 核心模板

### 1. 等价类 key

```java
Map<String, List<String>> groups = new HashMap<>();
for (String s : strs) {
    int[] freq = new int[26];
    for (char c : s.toCharArray()) {
        freq[c - 'a']++;
    }
    String key = Arrays.toString(freq);
    groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
}
```

## 今日必须说清的六个不变量

- `49`：同一字母多重集必须映射到同一个稳定表示。
- `242`：字符集固定时，计数直接比较比排序更低成本。
- `128`：只有没有前驱的数才允许启动扩展，所以每个数最多被 while 消耗一次。
- `560`：当前位置新增答案，等于之前出现过多少次 `prefix - k`。
- `525`：同一个平衡值再次出现时，最早下标给出最长合法区间。
- `974`：两个前缀的归一化模相同，差值才一定能被 `k` 整除。

## 高频错误

- 把 `49` 的 key 设计当成死记硬背，没有从“等价类表示”去理解。
- 在 `242` 上先写排序，再回头修改，说明默认模式还不稳定。
- 在 `128` 上会写 HashSet，但讲不清为什么不是平方复杂度。
- 在 `560` 上写反了顺序，先插当前前缀再查询目标差值。
- 在 `525` 上覆盖最早下标，导致最长区间被缩短。
- 在 `974` 上忘记 `((x % k) + k) % k`，负数前缀直接失真。

## 复杂度速记

- `49`：时间 `O(n * m)`，空间 `O(n * m)`
- `242`：时间 `O(m)`，空间 `O(1)`
- `128`：时间 `O(n)`，空间 `O(n)`
- `560`：时间 `O(n)`，空间 `O(n)`
- `525`：时间 `O(n)`，空间 `O(n)`
- `974`：时间 `O(n)`，空间 `O(min(n, k))`
- `383`：时间 `O(m + n)`，空间 `O(1)`
- `930`：时间 `O(n)`，空间 `O(n)`
